# DexSearch

Offline Pokédex and team builder for Android. Every Pokémon, form, move, ability and held item from Gen 1 to Gen 9,
per-game Pokédexes and TMs, type chart, Smogon sets, teams exported for Showdown. All data ships in `assets/`; the
network is used only to check for and download updates.

UI languages: English, Polski, Español, 日本語.

## Build

Needs the Android SDK (platform `android-36`, build-tools `36.0.0`), JDK 17+ and the Kotlin 2.x compiler
(`kotlinc` on `PATH`, or `KOTLINC=/path/to/kotlinc`). No Gradle.

```
./build.sh
adb install -r dexsearch.apk
```

The build runs a data self-check (`demo.dex.Dex`) before packaging. The versionCode is the commit count
(`VERSION_CODE=n ./build.sh` overrides it).

## Updates

`./publish.sh` builds the committed state, pushes it and creates release `v<versionCode>` with the APK. The release
starts `.github/workflows/pages.yml`, which puts `dexsearch.apk` and `version` on GitHub Pages
(`https://d3andark.github.io/dexsearch/`, set as `Update.BASE`). The app reads `version` on launch and, when it is
newer, offers the update on the home screen. Once: in repository Settings > Pages, set Source to "GitHub Actions".

On the phone the first update asks to allow "Install unknown apps" for DexSearch and to confirm; later ones install
without the system's confirm (Android 14+ via `UPDATE_PACKAGES_WITHOUT_USER_ACTION`). Google Play Protect still asks
about every new APK, since it has not seen it: "More details", then "Install without scanning". Updates must be
signed with the same `debug.keystore`, so keep it.

## iPhone

The Android app cannot run on iOS: it is built on `android.view` / `android.widget`, and a native iOS build would need
a Mac with Xcode and, without a paid developer account, a re-sign every 7 days. So `web/` holds the same app as a web
app, on the same `assets/` and translations, which Safari installs on the home screen with no account. It is built
into GitHub Pages by the same workflow on every release.

1. In Safari open `https://d3andark.github.io/dexsearch/`.
2. Tap Share (the square with an arrow; on iOS 26 it is under ⋯), then "Add to Home Screen", leave "Open as Web App"
   on where iOS shows it, then "Add".
3. Open DexSearch from the new icon. The first launch downloads about 25 MB; after that it works offline.

Opened in Safari but not installed, the home screen shows "Install DexSearch on this iPhone" with these steps.

Settings > Pokémon artwork picks 3D, official or pixel art; the picked style downloads in the background (18 or 1 MB),
shiny pictures as they are shown.

When a newer release is on Pages, the home screen shows "Update available"; tap it. Teams are stored in the web app on
that phone only, and deleting the icon deletes them, so keep a copy with "Copy as text".

On a computer the same address works in any current browser. From 900 px wide, the Pokédex and lists use more
columns and the Pokémon page keeps its picture beside the tabs. Chrome and Edge install it as an app from the icon in
the address bar, and Safari on a Mac from File > Add to Dock.

Locally: `web/build.sh /tmp/site` (runs `node web/check.js assets` first), then serve that folder over HTTP.

Without an iPhone: the same page opens in Chrome on Android (same code, Blink instead of WebKit) and in GNOME Web
(`dnf install epiphany`), which is WebKit like Safari. Playwright's `webkit` with `devices['iPhone 13']` runs it
headless; on Fedora it needs ICU 74 and `libjpeg.so.8` from Ubuntu 24.04, as Playwright builds WebKit for Ubuntu.

## Data

`assets/` is generated by `gen_data.py` (it runs the other `gen_*.py` scripts) and committed, so a build needs no
download. Sources: [PokeAPI](https://github.com/PokeAPI/pokeapi) data and sprites,
[Pokémon Showdown](https://github.com/smogon/pokemon-showdown), [Smogon](https://www.smogon.com/) sets via
[pkmn](https://pkmn.github.io/smogon/), [PvPoke](https://github.com/pvpoke/pvpoke) and [pokemondb.net](https://pokemondb.net/).
